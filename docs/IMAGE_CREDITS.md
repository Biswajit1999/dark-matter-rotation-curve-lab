# Observational image credits

The application uses static, real observatory products. It contains no AI-generated
images, synthetic galaxy artwork or animated GIF hero media. Images are stored
locally so the interface remains stable and each visible card links to its primary
source page.

## Hubble Messier 51

- Local file: `assets/observations/hubble-m51.webp`
- Source: <https://science.nasa.gov/image-detail/hubble_m51/>
- Direct file: <https://science.nasa.gov/wp-content/uploads/2023/04/hubble_m51-jpg-e1688472875538.webp>
- Credit: NASA, ESA, S. Beckwith (STScI), and the Hubble Heritage Team
  (STScI/AURA)
- Context: a real Hubble observation used to show spiral-galaxy morphology. It is
  not represented as an image of any selected SPARC target.

## Bullet Cluster, 1E 0657-56

- Local file: `assets/observations/bullet-cluster-lensing.jpg`
- Source: <https://chandra.harvard.edu/photo/2025/bullet/more.html>
- Direct file: <https://chandra.harvard.edu/photo/2025/bullet/bullet_dashed.jpg>
- Credit: X-ray: NASA/CXC/SAO; near-infrared: NASA/ESA/CSA/STScI; image
