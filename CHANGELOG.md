# Changelog

## 3.0.0-beta.4 - 2026-09-28

### Scientific inference
- Added fixed distance/inclination sensitivity experiments for SPARC rotation curves.
- Added prior-predictive intervals, chain traces and autocorrelation diagnostics.
- Wired A-J galaxy evidence storytelling and the complete population selection controls.
- Added reproducible analysis URLs and stronger exported state metadata.
- Extended the cosmology engine with CPL w0-wa evolution, H(z), comoving distance and BAO-style distance coordinates.
- Updated the Bullet Cluster record with the 2025 JWST strong+weak lensing reconstruction.
- Timestamped the experiment atlas and encoded the September 2026 LZ high-energy event as a background tension/anomaly, not a discovery.

### Physics-constrained futures
- Added local dark-matter mass, kinetic-energy and momentum flux calculations.
- Added optical-depth interaction probability and a conservation-law propulsion/energy sandbox.
- Added an explicit extra-dimensions hypothesis module that states extra dimensions are not required for electromagnetic darkness.

### Reproducibility and publication
- Added PR-based `npm run verify` CI.
- Added an independent SciPy least-squares validation implementation.
- Added a machine-readable open-problem registry.
- Began the final publication/monograph package.

### Scientific boundary
This release does not claim to identify dark matter, discover evolving dark
energy, reconstruct published lensing shear catalogues from raw data, or
demonstrate a practical dark-matter engine.
