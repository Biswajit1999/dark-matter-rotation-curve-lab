# Open problems registry

This file is the human-readable companion to `data/open_problems.json`. It is
not a list of claims that this repository has solved. Each item is a question
whose status should change when new data, analysis or theory changes the
evidence.

## Research contract

For every open problem, record the question, why it matters, governing
equations, current evidence, competing explanations, relevant datasets,
a discriminating measurement, falsification criteria, degeneracies/systematics,
status and references. If a result is not supported by available evidence,
add or update an open-problem record instead of inventing an answer.
